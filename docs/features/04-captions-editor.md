# F4 — Sous-titres animés, éditeur et export

## Styles (20 au lancement)
Inspiration : viral (mot par mot, rebond), karaoké (surlignage progressif), cinéma, néon, minimal, gras centré, typewriter, highlight box, gradient, 3D shadow, podcast deux intervenants (couleur par personne), etc.
Chaque style = un objet de configuration typé (`CaptionStyle`) : police, taille, couleurs, contour, ombre, fond, animation d'entrée/sortie, nombre de mots par ligne, casse, emojis auto.

## Éditeur
- Aperçu `@remotion/player` à gauche, panneau de style à droite, timeline en bas.
- Déplacer les sous-titres à la souris (position en % du cadre, pour rester identique dans tous les formats).
- Mots forts : clic sur un mot → couleur/échelle d'accent ; option « mots forts automatiques » (IA).
- Annuler/rétablir (Ctrl+Z / Ctrl+Y), sauvegarde automatique.
- Mobile : éditeur simplifié (choix du style, correction du texte, export).

## Export
- Formats 9:16, 1:1, 16:9 ; 720p / 1080p ; MP4 H.264 + AAC.
- Export du fichier SRT/VTT en plus (gratuit).
- Plan gratuit : filigrane discret.
- Rendu = même composition Remotion que l'aperçu (règle d'or).
